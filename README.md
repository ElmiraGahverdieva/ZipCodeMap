# ZIP Code Map (Windows)

Интерактивная карта зон ZIP-кодов США (ZCTA) с возможностью отметить
"исключённые" зоны (ZIP, округа, штаты, страны, провинции, конгрессиональные
округа, county subdivisions, Nielsen DMA).

Эта ветка (`Win`) настроена и проверена статически для запуска на Windows.
Тот же код работает и на Mac/Linux (см. основную ветку) — там команда
называется `python3`, а не `python`, и вместо `start.bat` используется
`./start.sh`.

## Что нужно установить

- **Python 3** (3.8+) — https://www.python.org/downloads/
  При установке **обязательно отметьте галочку "Add python.exe to PATH"**
  на первом экране инсталлятора — без неё команда `python` не будет
  находиться в терминале.
  Проверить после установки: `python --version`
- Интернет — для первичной загрузки справочников (один раз)
- Библиотека `pyshp` — устанавливается автоматически при первом запуске

Никакого Node.js, баз данных или серверов устанавливать не нужно — всё
работает локально через `python server.py`.

## Быстрый старт

Дважды кликнуть **`start.bat`** в папке проекта (или запустить его из
командной строки/PowerShell).

`start.bat` сам находит `python` (или `py`, если `python` не в PATH),
запускает `setup.py` (если базы `zcta.db` ещё нет), а затем `server.py`,
который откроет браузер на `http://localhost:8888`.

Если `start.bat` не запускается — Windows иногда блокирует .bat-файлы,
скачанные из интернета (SmartScreen). Открыть свойства файла → снять
галочку "Разблокировать" ("Unblock"), либо запустить вручную из
командной строки:

```bat
cd ZipCodeMap
python setup.py
python server.py
```

## Какие справочники скачиваются и откуда

`setup.py` собирает локальную базу `zcta.db` (SQLite) из нескольких источников:

| Данные | Источник | Как получить | Блокировки |
|--------|----------|---------------|------------|
| ZIP-зоны США (ZCTA) | Census Bureau (`www2.census.gov`) | автоматически при `python setup.py` | ⚠️ Часто блокируется Cloudflare |
| Страны мира | Natural Earth (S3) | автоматически | ✅ Без проблем |
| Регионы/провинции мира (штаты США, провинции Канады и т.д.) | Natural Earth (S3) | автоматически | ✅ Без проблем |
| Округа США (counties) | Census Bureau | автоматически | ⚠️ Часто блокируется Cloudflare |
| Nielsen DMA (рынки телевещания) | bundled `nielsen_dma_counties.csv` | автоматически, без скачивания | ✅ |
| ZIP→ZCTA crosswalk (заполняет ZIP без своей ZCTA) | bundled `zip_zcta_crosswalk.csv` (HRSA) | автоматически, без скачивания | ✅ |
| Округа-подразделения (townships/precincts) | Census Bureau, 51 файл по штатам | `python setup.py --cousub` (отдельно, не по умолчанию) | ⚠️ Возможны частичные блокировки |
| Конгрессиональные округа | Census Bureau, единый файл | `python setup.py --cd` (отдельно, не по умолчанию) | ⚠️ Возможна блокировка |

`setup.py` (без флагов) пробует скачать первые шесть строк автоматически.
Natural Earth и bundled-файлы скачаются гарантированно. ZCTA и округа США
**могут не скачаться** из-за блокировки Cloudflare — в этом случае нужно
скачать вручную (см. ниже), карта при этом всё равно частично работает.

### Если ZCTA (ZIP-зоны) не скачались автоматически

`setup.py` напишет:
```
❌ Скачайте вручную в браузере:
   https://www2.census.gov/geo/tiger/GENZ2020/shp/cb_2020_us_zcta520_500k.zip
   Затем: python setup.py --file cb_2020_us_zcta520_500k.zip
```

1. Открыть эту ссылку в обычном браузере (Cloudflare пропускает браузер,
   но не блокирует автоматические запросы) и скачать zip-файл
2. Положить скачанный файл в папку `ZipCodeMap`
3. Запустить:
   ```bat
   python setup.py --file cb_2020_us_zcta520_500k.zip
   ```

### Если округа США (counties) не скачались автоматически

Сама карта продолжит работать без округов (просто не будет показывать
county/state контекст при наведении на ZIP). Если они всё же нужны —
скачать вручную аналогично:

1. Открыть в браузере:
   `https://www2.census.gov/geo/tiger/GENZ2020/shp/cb_2020_us_county_500k.zip`
2. Положить файл в папку `ZipCodeMap`, переименовать под код, который ждёт
   `setup.py`, либо попросить разработчика добавить `--counties-file` флаг
   (на момент написания этого README такого флага нет — счётчик округов
   просто пропускается с предупреждением, это не критично).

### Пересборка базы

```bat
python setup.py --rebuild
```
Удалит `zcta.db` и пересоберёт всё с нуля (кроме `--cousub`/`--cd` — их
нужно запускать заново отдельно).

### Дозагрузка недостающих справочников

Если `zcta.db` уже существует, но в нём не хватает каких-то таблиц (например,
у тебя уже есть ZIP-зоны, но нет стран/регионов мира), `setup.py` сам
определит это и скачает только недостающее — полную пересборку запускать
не нужно, достаточно:

```bat
python setup.py
```

## Как переслать готовую базу другому человеку (без повторного скачивания)

Самый простой способ — передать уже собранную папку, чтобы получателю не
пришлось бороться с блокировками Census Bureau: выделить все файлы папки
в Проводнике → правый клик → **"Отправить" → "Сжатая ZIP-папка"**
(либо в PowerShell: `Compress-Archive -Path * -DestinationPath ZipCodeMap.zip`).

Это включит уже готовый `zcta.db` со всеми справочниками. Получателю
останется:
1. Установить Python 3 (отметить "Add python.exe to PATH")
2. Распаковать архив
3. Запустить `start.bat` (или `python server.py` вручную) — без `setup.py`,
   база уже на месте

Размер архива зависит от того, какие справочники собраны (обычно от
нескольких десятков до ~300+ МБ, если собраны все опциональные слои —
county subdivisions и конгрессиональные округа).

## Структура файлов

- `index.html` — фронтенд (карта, Leaflet.js)
- `server.py` — локальный HTTP-сервер, отвечает на `/api/*` запросы из SQLite
- `setup.py` — единоразовая загрузка и сборка справочников в `zcta.db`
- `start.bat` — запускает `setup.py` (если нужно) и `server.py` (Windows)
- `zcta.db` — собранная база (не в git, создаётся локально)
- `download_data.py` — вспомогательный диагностический загрузчик
- `nielsen_dma_counties.csv`, `zip_zcta_crosswalk.csv` — bundled справочники,
  используются `setup.py` без скачивания
